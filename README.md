# Doctor-Appointment-Booking-Application

This is an innovative doctor appointment booking application developed using MERN Stack (MongoDB, Express, React, Node.js) that aims to provide a seamless, intuitive, and efficient platform where patients can easily book, manage, cancel appointments and pay doctor’s fee with ease. The application also allows the admin to manage all appointments, add doctor, cancel appointment and appointment completion with proper authorization. The application provides a robust and scalable platform to manage the process of appointment booking.

Key Features :-

### Key Features

* **Appointment Booking:** Patients can schedule appointments with available doctors based on their availability.

* **Appointment Cancellation:** Patients can cancel their scheduled appointments when required.

* **Secure Fee Payment:** Patients can securely pay the consultation fee for their selected doctor.

* **Admin Appointment Management:** Admin can view and manage all patient appointments from the system.

* **Doctor Management:** Admin can add and manage doctors within the application.

* **Appointment Completion:** Admin can mark appointments as completed after the consultation.

* **Authorization:** Role-based authorization ensures that patients and administrators can access only the features relevant to their roles.

* **Scalable Platform:** The application provides an efficient and scalable solution for managing the complete doctor appointment booking process.

This application aims to improve accessibility, reduce wait times, and streamline the management of appointments while also providing secure payment processing.
